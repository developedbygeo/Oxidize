date: 2026-06-02

A foundational release. Oxidize now handles video end-to-end via an ffmpeg sidecar, ships a full image pipeline (crop, rotate, resize, beautify, effects, convert, compress), and adds watermarking + social-media presets across both media types.

## Highlights

- Watermark images and videos with a 9-cell position grid
- Full video pipeline — convert, compress, resize, trim, extract audio
- Social media presets across Instagram, TikTok, YouTube, LinkedIn, Facebook, X, and Pinterest
- Image pipeline — chain crop → beautify → effects → convert → compress
- AVIF output, clipboard paste, filename templates, EXIF/ICC preservation
- Persistent settings — per-page form defaults, theme, last-visited page

## New

- **Watermark — images.** New WatermarkPage with a 9-cell anchor grid, opacity / size / margin sliders, and a live CSS preview. Hand-rolled per-pixel alpha composite so partial opacity is honoured.
- **Watermark — videos.** ffmpeg overlay filter driven by the same position model. Audio passes through; same controls as the image side.
- **Video Convert.** Change container/codec across MP4, WebM, MKV, MOV, and AVI.
- **Video Compress.** CRF / bitrate modes with codec-specific speed flags (VP9 row-mt, x264 preset).
- **Video Resize.** Preset-height (720p / 1080p / etc.) or custom dimensions, optionally maintaining aspect ratio.
- **Video Trim.** Per-file scrub-and-trim with Accurate (re-encode, frame-perfect) or Fast (stream-copy) modes.
- **Extract Audio.** Pull MP3, AAC, Opus, FLAC, or WAV out of any source video with bitrate selection.
- **Pipeline.** Chain Crop → Beautify → Effects → Convert → Compress in a single in-memory run, no intermediate files.
- **Image Crop.** Standalone CropPage and pipeline step with aspect-ratio presets and a hand-rolled crop canvas.
- **Image Rotate + Flip.** Quarter-turn rotation and horizontal/vertical flips composed Photoshop-style, with a live CSS preview.
- **Image Resize.** Cover / Contain / Stretch fit modes, Lanczos3 resampling, single-axis or both.
- **Social Media Presets.** 29 platform-correct presets for Instagram, TikTok, YouTube, LinkedIn, Facebook, X, and Pinterest. Routes through resize automatically.
- **AVIF output.** Pure-Rust ravif encoder, no C dependencies. Available across Convert, Compress, and the Pipeline.
- **Clipboard paste.** Ctrl/Cmd+V on any image page pastes a clipboard image into the dropzone.
- **Filename templates + overwrite modes.** Use `{name}` / `{op}` / `{date}` / `{time}` / `{width}` / `{height}` placeholders. Choose auto-number, skip, or overwrite on collision.
- **EXIF / ICC preservation.** Toggle on Compress to carry metadata through JPEG and lossless PNG outputs.
- **Keyboard shortcuts.** Ctrl+1..9 for nav, Ctrl+Enter to run, Esc to cancel, Ctrl+/ for the cheat-sheet.
- **Persistent settings.** Theme, last-visited page, and per-page form defaults persist across launches.

## Improvements

- **Drag-and-drop from the OS.** Both image and video dropzones light up during native OS drags.
- **Friendlier error messages.** ffmpeg and image-codec errors are matched against common patterns and surfaced with a structured title + description.
- **Job progress bar with locked ETA.** Per-file progress with elapsed time, locked-and-re-anchored ETA, and a single Cancel button.
- **Batch cancellation.** Esc cancels image batches too (matching the video flow). Already-running items finish; the rest short-circuit with a Cancelled toast.
- **File-size guard rails.** Soft warning toast when an image >100MB or a video >2GB enters the dropzone.
- **Open folder / Reveal file actions.** Every result row reveals the file in the OS file manager. Every results banner has an Open folder button.
- **Source preview on Convert / Compress.** Step through the source images before processing with per-image meta.
- **Empty-state teasers.** Convert / Compress / Pipeline empty states preview the formats and operations available.
- **Faster VP9 encoding.** `-row-mt 1 -cpu-used 4 -deadline good` cuts WebM encode time meaningfully.
- **Quality slider UX.** Video CRF is now displayed as Quality 0–100% with CRF shown as subtext, matching the image-side mental model.
- **Sidebar groups.** Social / Image / Video / History groups keep the nav navigable.
- **Test coverage.** 300+ frontend tests (Vitest) and 100+ Rust tests (cargo) cover pure transforms, schemas, executions, and component behaviour.

## Fixes

- **Windows path handling.** `reveal_file` now passes a raw `OsStr` instead of `to_string_lossy`, preserving non-UTF-8 path bytes.
